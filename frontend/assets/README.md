# Assets

Pour afficher le branding officiel Google sur le bouton « Continuer avec Google »,
dépose ici les fichiers **officiels** de Google (depuis les Google brand guidelines /
le package google_sign_in) :

- `google_logo.png` — le logo « G » multicolore officiel (≈ 48×48, fond transparent)
- `google_wordmark.png` — le logo-texte « Google » officiel (optionnel)

Le bouton les charge automatiquement dès qu'ils sont présents (déclarés via
`assets/` dans pubspec.yaml). Tant qu'ils ne sont pas là, un repli s'affiche.
Ne pas recréer le logo à la main : utiliser le fichier officiel de Google.
